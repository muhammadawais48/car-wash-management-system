# Car Wash Management System

A web-based car wash management system where customers can view washing
plans and book appointments, and the admin can manage bookings, washing
points and enquiries. Built as our BS Computer Science final year project
(Government College University Faisalabad, 2023).

## Features

**Customer side**
- Home, About Us, Washing Plans, Washing Points and Contact Us pages
- Premium washing services page
- Get Appointment (booking form)
- Enquiry / Get In Touch form

**Admin side**
- Secure admin login and change password
- Dashboard
- Add and manage washing points
- Add, view, update and delete car washing bookings
- Manage customer enquiries
- Manage website pages
- Print reports

## Technologies Used
- PHP (backend)
- MySQL (database), XAMPP (local server)
- HTML, CSS, Bootstrap (frontend)
- Sublime Text (editor)

## Database Tables
Login, Car Washing Booking, Enquiry, Pages, Washing Points

## How to Run Locally
1. Install XAMPP and start Apache and MySQL
2. Copy the project folder into `htdocs`
3. Open phpMyAdmin, create a database and import the `.sql` file
4. Update the database settings in the config file
5. Open `http://localhost/car-wash-management-system` in your browser
